# Mission 02 · Station in Motion

Самостоятельный HTML-воркщит в оформлении Frozen Station. Откройте `index.html` в браузере. Интернет и установка пакетов для учеников не нужны. Сохраните рядом все файлы CSS/JS и папку `assets`: там находятся иллюстрации и записи слов. Внешних шрифтов, библиотек и сервисов при работе страницы нет.

## Задания

1. **Sorting:** 12 перемешанных карточек-ситуаций, четыре отдельные категории: open, close, send, receive. Открытие/закрытие показано двумя состояниями предмета; направление передачи — стрелкой относительно персонажа YOU. На картинках нет готовых подписей с искомыми глаголами.
   - open: window, box, gate;
   - close: bag, book, door;
   - send: postcard, gift, photo;
   - receive: letter, parcel, message.
   Это список для новой реализации, а не восстановленный список из прежней переписки.
2. **What is happening now?** Пять анимированных сцен: открывающиеся ворота, отправляющее сообщения радио, закрывающаяся дверь, неисправный экран, вращающийся вентилятор. Стрелки сохраняют смысл при остановленной анимации и печати. Ученик заканчивает предложения по изображениям; банк слов перемешан. В новом варианте есть утвердительные и отрицательное предложения вместо пяти выдуманных неисправностей.
3. **Usually / now:** две письменные пары по справочнику и камерам, сообщение Тико с because, чтение вслух. Эти части проверяет учитель.

Правильные ответы раздела 1 приведены здесь для учителя. Ученикам отправляется ссылка на страницу `index.html`.

## Сохранение и проверка

Ответы, порядок карточек и банка слов сохраняются в localStorage этого браузера. Автоматической отправки учителю нет. Для передачи работы можно распечатать заполненную страницу или сохранить её в PDF через меню печати. Новый адрес страницы или другой браузер не переносит старые ответы.

Check sorting и Check sentences дают проверку и позволяют исправить ошибку. Start again запрашивает подтверждение и начинает новую попытку. Браузер без доступа к localStorage показывает предупреждение; работать можно, но сохранение недоступно.

## GitHub Pages

Для публикации загрузите `index.html`, все файлы CSS/JS и папку `assets` (включая `assets/audio`) в одну папку репозитория, сохранив структуру. Затем включите GitHub Pages для выбранной ветки/папки. При размещении в корне это будет главная страница сайта. Никакой сборки и внешних библиотек нет.

## Новое оформление

Сгенерированы встроенным image_gen: панорама обсерватории, 18 состояний и предметов в инвентарном атласе, сцены пяти камер и новая поза Тико по утверждённому листу персонажа. Подписи с ответами на картинки не нанесены. Шаги доступны через навигацию; действия выбираются на панели под ней. Форма отчёта оформлена как полевой блокнот. Ответы прежней HTML-версии сохранены: ключ localStorage не изменён.

Промпты находятся в `docs/mission02-homework-review/image-prompts.json` в исходном проекте.

## Движение и открытый дневник

Ворота поднимаются отдельным слоем; дверь закрывается с поворотом вокруг левого края. Письмо заменено отдельным ровным изображением конверта. Экран остаётся неисправным: мигает индикатор и видна неудачная попытка запуска. Кнопка Pause cameras останавливает также маленькие камеры в дневнике; reduced-motion оставляет статические стрелки и последовательности состояний.

Карточки перемешиваются без соседних одинаковых категорий. Порядок сохраняется между открытиями и не меняется при выборе/проверке. Mix cards явно меняет порядок, сохраняя ответы. Старая группировка один раз перемешивается при переходе на эту редакцию; сами ответы и записи не стираются.

Третье задание — настоящий сгенерированный разворот дневника. На левой странице вводятся два сравнения, на правой — сообщение Тико. На телефоне страницы расположены одна под другой. Все три текстовых поля сохраняются под прежними ключами.

Новые ассеты сгенерированы встроенным image_gen. Промпты этой правки: `docs/mission02-homework-review/image-prompts-diary-motion.json`.

## Озвучка первого задания

Четыре глагола (open, close, send, receive) и все 12 предметов имеют отдельные кнопки прослушивания. Кнопки динамиков не выбирают карточку или ответ. Повторное нажатие запускает слово сначала; при выборе другого слова предыдущее останавливается. Смена порядка и проверка не убирают кнопки.

16 записей MP3 подготовлены через edge_tts голосом en-GB-RyanNeural, темп -12%, и сохранены в `assets/audio`. После подготовки приложение играет локальные файлы без подключения к сервису синтеза речи. Метаданные: `assets/audio/manifest.json`. Скрипт подготовки в проекте: `scripts/build_mission02_homework_audio.py`.

## Загрузка картинок

Страница использует облегчённые WebP-иллюстрации. Предметы первого задания выводятся настоящими изображениями, с приоритетной загрузкой общего атласа. Пока источник не загрузился, карточка показывает Loading picture и не принимает ответ. При ошибке доступна Retry pictures; сохранённые ответы не стираются. Для публикации нужны также `card-art.css` и `card-art.js`. PNG-оригиналы сохранены в исходном проекте; обновлённый ZIP включает необходимые WebP-файлы.

Предыдущий `Station Designer.png` сохранён как отдельный прежний вариант. HTML-версия публикуется в корне существующего EngHomework; встроенная в приложение ссылка на прежний PNG не меняется этой правкой.

## Два блока для проговаривания · 25 октября 2026

В начале, до Action lab, расположен **Listen and repeat!**: четыре глагола, пять названий предметов и короткие конструкции. Запись `listen-repeat-start.mp3` длится около 1:32; после каждого слова или словосочетания есть настоящая трёхсекундная тишина для ответа ученика.

В конце расположен **Let’s say it!**. Запись `listen-repeat-final.mp3` длится около 2:02. Она содержит сообщение Тико о пяти камерах, два сравнения usually/now и просьбу проверить экран. Длинные сравнения сначала звучат по частям, затем целиком. Между фразами оставлены паузы 4–6 секунд. После повторения ученик читает вслух свои два сравнения и собственное сообщение Тико.

Конечная запись и её текст открываются после самостоятельной попытки: нужно заполнить пять предложений по камерам, нажать Check sentences и написать два сравнения и сообщение. Верные ответы для открытия не требуются. После открытия запись остаётся доступной при исправлении работы. Между заданиями новых блоков нет.

Прослушивание, пауза, перемотка и Replay доступны без сети; одновременно играет только одна запись. Отметки «повторил вслух» выставляет ученик: само воспроизведение не подтверждает произнесение и не записывает голос. Ошибка загрузки допускает повторную попытку. Сохранение использует прежний ключ localStorage: ответы, порядок карточек и написанный текст сохраняются. Новые отметки размещены в `speaking`; Start again очищает их только после явного подтверждения.

При публикации нужны также `speaking.css`, `speaking.js`, два MP3 и `assets/audio/repeat-manifest.json`. Старые записи отдельных слов остаются. Скрипт `scripts/build_mission02_repeat_audio.py` создаёт речь через edge_tts (Ryan, en-GB, −18%), затем соединяет её с реальными паузами; манифест хранит точные границы речи и тишины. Проверки: `tests/check_mission02_repeat.py`, `tests/check_mission02_homework_html.py`, `tests/check_mission02_homework_audio.py`. Проверены декодированная речь и тишина, прослушивание, ошибка/повтор, восстановление, явный сброс, мобильный вид, печать и работа из папки без сети.
