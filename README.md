# English Quest · Homework

Interactive English homework for A1 Movers.

## Mission 01 — My First Expedition

- [Movers](https://karnouhovaiana33-png.github.io/EngHomework/mission-01/): two qualities, two because reasons, two skills and five recap gaps.
- [Starters — separate simpler version](https://karnouhovaiana33-png.github.io/EngHomework/mission-01/starters/): one quality, one skill, four short sentences and three short listening clips.

Both versions include Tiko's introduction, an illustrated drawable ID card, diary writing, pronunciation, persistent answers and printing. Each version saves separately.

## Mission 02 — Station in Motion

- Sort twelve illustrated cards using four actions.
- Watch five animated station cameras and describe what is happening.
- Write comparisons and a message for Tiko in an open field diary.
- Listen to British English pronunciation with the speaker buttons.

Open `index.html` in a browser, keeping the CSS, JavaScript and `assets` folder beside it. No installation or build step is needed. Images and word recordings work offline.

Answers save in the same browser on the same device. The worksheet does not send answers to the teacher. Use Print worksheet to print or save a PDF. Start again begins a new attempt after confirmation.

For GitHub Pages, use the `main` branch and `/ (root)` folder in the repository's Pages settings.
